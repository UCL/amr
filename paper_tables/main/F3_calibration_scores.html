Figure F3 — Calibration Block Scores

Normalised block scores for the accepted calibration runs (n = 2). Scores ≤ 1.0 (dashed line) indicate all targets within the block are within tolerance. Blue = accepted; red = failed. Error bars show 5th-95th percentile ranges across accepted runs.

[Download SVG]

  1. Block scores are normalised so that 1.0 represents the acceptance boundary. A score below 1.0 means all targets in that calibration block are within the specified absolute or relative tolerance.
  2. The overall calibration score is the weighted sum across blocks. Calibration is considered accepted when the overall weighted score ≤ 1.0.
