# Historical Archive

This directory contains source-stamped historical evidence retained for model
development and reproducibility. Nothing here is compiled, loaded by the model,
or consumed by the Python analysis package.

The current executable inventories are in `src/simulation/population.rs`, and
the current parameter set is in `src/config.rs`. Historical files may therefore
contain retired names, superseded structures, and values that must not be copied
into the current model without an explicit review.
