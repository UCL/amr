# Model-comparison overlay provenance

The seven `calibration_*_empirical.csv` files are retained because their broad
patterns can be useful for model diagnostics. They are not part of the
calibration score used for grouped Figures 1-5.

The historical files do not contain sufficient row-level citations to support
calling their values observed empirical estimates. Some rows are known to be
algorithmically generated; others carry a surveillance, sales, trial, or study
family label but their exact observation provenance cannot be recovered. The
numerical values are therefore retained under one of two non-observational
classes:

- `generated_best_guess_placeholder`
- `source_informed_best_guess_placeholder_provenance_unverified`

`overlay_provenance_v1.csv` assigns these classes by file and, where needed,
by the legacy `source_quality` value. The production loader excludes both
classes by default. They can be displayed only through the explicit
`show_best_guess_placeholder_overlays` plotting option, and plots must label
them as best-guess placeholders rather than observed or empirical data.

A future row may use `observed_comparison` only when it explicitly records
`generated=false`, a source identifier, URL or DOI, reference year,
uncertainty interpretation, rationale, and review date. A source-family name
alone is never sufficient.

The ignored source-shaped files under `data/who`, `data/ecdc`,
`data/australia`, and `data/cddep` were generated by
`amr_simulation_output_analysis/empirical/acquire_empirical_data.py`. Their
authoritative-looking names describe intended schemas, not downloaded
observations.
