## Summary Statistics

### Mechanisms with Limited Applicability

**Highly Specific Mechanisms:**
- `TargetSitePbp2aMecA` (mecA): Only Staphylococcus species (2/42 bacteria = 4.8%)
- `TargetSiteVanA`/`VanB`: Only Gram-positive bacteria, primarily Enterococcus (8/42 bacteria = 19%)
- `EffluxMexxyOprm`: Primarily Pseudomonas (1-2/42 bacteria = 2-5%)
- `PorinLossOprd`: Primarily Pseudomonas (1/42 bacteria = 2.4%)

**Gram-Stain Dependent:**
- ESBLs/Carbapenemases/AmpC: Gram-negative only (~28/42 bacteria = 67%)
- RND Efflux systems: Gram-negative only (~28/42 bacteria = 67%)
- Outer membrane porin loss: Gram-negative only (~28/42 bacteria = 67%)
- Colistin modification: Gram-negative only (~28/42 bacteria = 67%)

**Universally Applicable Mechanisms:**
- `MutationGyrAPrimary` - All bacteria
- `MutationGyrAParCSecondary` - All bacteria
- `Enzyme16sRrmt` - All bacteria
- `EnzymeCat` - All bacteria
- `GlobalEffluxPump` - All bacteria (though efficiency varies)
